# Step Into AR

WebAR-kampagne (studieprojekt, multimediedesign): scan QR-koden, peg kameraet mod gulvet eller bordet, og tryk for at stille skoen der. Swipe for at skifte model.

Tre måder at se skoen på:

- **AR uden plakat** (standard). Android/Chrome bruger WebXR med rigtig gulvgenkendelse. iPhone og andre browsere viser kamerabilledet, og telefonens gyroskop holder skoen på plads, når man kigger rundt.
- **AR med plakaten** (valgfri). Plakaten genkendes med MindAR, og skoen står på den.
- **3D** uden kamera.

- Live: https://aske0772.github.io/step-into-ar/
- Plakat + QR: https://aske0772.github.io/step-into-ar/qr.html

Bygget med three.js, WebXR og MindAR.

Studieprojekt. Ikke tilknyttet eller godkendt af Nike.

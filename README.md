# Step Into AR

WebAR-kampagne (studieprojekt, multimediedesign): scan QR-koden, peg kameraet mod plakaten, og skoene springer frem i 3D. Swipe for at skifte model.

- Live: https://aske0772.github.io/step-into-ar/
- Plakat + QR: https://aske0772.github.io/step-into-ar/qr.html

Bygget med three.js og MindAR (billedgenkendelse i browseren).

Studieprojekt – ikke tilknyttet eller godkendt af Nike.
